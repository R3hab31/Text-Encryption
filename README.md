# \## Overview

# A cybersecurity project developed during my Pinnacle internship to explore cryptographic techniques for protecting text data. The project covers symmetric encryption, asymmetric cryptography, digital signatures, and hybrid encryption approaches.

# 

# \## Cryptographic Techniques

# 

# \- \*\*RSA:\*\* Asymmetric cryptography used for encryption and decryption, or digital signatures, depending on the implementation.

# \- \*\*DSA:\*\* Digital Signature Algorithm used to generate and verify digital signatures, helping establish message authenticity and integrity.

# \- \*\*AES:\*\* Symmetric encryption algorithm used to encrypt and decrypt text data using a secret key.

# \- \*\*Hybrid Cryptography:\*\* Combines symmetric and asymmetric cryptography, typically using AES to encrypt the message and RSA to protect the AES key.

#
